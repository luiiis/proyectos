# 🇺🇸 Academia de Inglés — De Cero a Profesional

## Para Desarrolladores de Software que Hablan Español

Esta academia está diseñada para un programador hispanohablante que necesita inglés para:
- Leer documentación técnica
- Entrevistas de trabajo en inglés
- Reuniones con equipos internacionales
- Escribir código, comments, PRs y emails profesionales

---

## Estructura

```
english-learning/
├── 01-pronunciacion/        → Cómo se pronuncia cada sonido (español → inglés)
├── 02-vocabulario-basico/   → 500 palabras esenciales con pronunciación
├── 03-gramatica-basica/     → Estructura de oraciones, tiempos verbales
├── 04-conversacion/         → Frases del día a día
├── 05-vocabulario-tech/     → Inglés para programadores (el más importante)
├── 06-gramatica-media/      → Tiempos compuestos, condicionales, pasiva
├── 07-lectura/              → Leer documentación, artículos, PRs
├── 08-escritura/            → Emails, commits, code reviews, PRs
├── 09-listening/            → Entender hablantes nativos, meetings
├── 10-entrevistas/          → Preguntas y respuestas para interviews
├── 11-presentaciones/       → Hablar en público, demos técnicas
├── 12-avanzado/             → Expresiones idiomáticas, humor, cultura
└── recursos/                → Apps, canales, podcasts recomendados
```

## Cómo Usar

```
Semana 1-4:   Módulos 01-02 (pronunciación + vocabulario básico)
Semana 5-8:   Módulos 03-04 (gramática + conversación)
Semana 9-12:  Módulo 05 (vocabulario tech — el MÁS importante para ti)
Semana 13-16: Módulos 06-07 (gramática media + lectura)
Semana 17-20: Módulos 08-09 (escritura + listening)
Semana 21-24: Módulos 10-12 (entrevistas + presentaciones + avanzado)
```

## Niveles

| Nivel | Equivalente | Lo que puedes hacer |
|-------|------------|---------------------|
| A1 (Principiante) | Módulos 01-02 | Saludar, presentarte, leer palabras sueltas |
| A2 (Básico) | Módulos 03-04 | Oraciones simples, conversación básica |
| B1 (Intermedio) | Módulos 05-07 | Leer docs técnicas, emails simples |
| B2 (Intermedio Alto) | Módulos 08-09 | Escribir PRs, entender meetings |
| C1 (Avanzado) | Módulos 10-12 | Entrevistas, presentaciones, negociación |

## Tip #1: Consistencia > Intensidad
```
30 minutos DIARIOS > 5 horas el domingo
La repetición crea memoria muscular (como programar)
```
