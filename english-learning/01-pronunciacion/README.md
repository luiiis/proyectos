# Módulo 01: Pronunciación — Guía de Español a Inglés

## La regla de oro
En español, cada letra se pronuncia SIEMPRE igual.
En inglés, las letras cambian de sonido según la palabra.
Por eso necesitas aprender SONIDOS, no letras.

---

## 1. Vocales — Las más difíciles para hispanohablantes

### Español tiene 5 vocales: a, e, i, o, u
### Inglés tiene ~15 sonidos vocálicos (muchos no existen en español)

| Sonido inglés | Cómo suena (aprox. español) | Ejemplo | Pronunciación |
|--------------|----------------------------|---------|---------------|
| /æ/ | Entre "a" y "e" (abre mucho la boca) | **cat** | "kæt" → suena como "kat" pero con la boca más abierta |
| /ɑː/ | "a" larga (como decir "aah" en el doctor) | **car** | "kaar" |
| /ʌ/ | "a" corta y relajada (como "a" dicha rápido) | **cup** | "cap" (rápido) |
| /ɪ/ | Entre "i" y "e" (corta y relajada) | **it** | no es "it" como español, es más relajada |
| /iː/ | "i" larga (como "iii") | **see** | "sii" |
| /ʊ/ | "u" corta (labios apenas redondeados) | **book** | "buk" (corta) |
| /uː/ | "u" larga | **food** | "fuud" |
| /ɒ/ | "o" corta con boca abierta | **hot** | "jot" (boca abierta) |
| /ɔː/ | "o" larga | **four** | "foor" |
| /ə/ | "Schwa" — el sonido MÁS común. Vocal relajada neutral | **about** | "əbáut" → la primera "a" es casi muda |
| /ɜː/ | Como decir "e" con labios redondeados | **bird** | "berd" (con la r suave) |
| /eɪ/ | "ei" (diptongo) | **day** | "dei" |
| /aɪ/ | "ai" (diptongo) | **my** | "mai" |
| /ɔɪ/ | "oi" (diptongo) | **boy** | "boi" |
| /aʊ/ | "au" (diptongo) | **how** | "jau" |
| /əʊ/ | "ou" (diptongo) | **go** | "gou" |

### La "schwa" /ə/ — aprende esto primero
Es el sonido vocal más común en inglés. Aparece en TODAS las sílabas no acentuadas.

```
about    → ə-BAUT (la "a" inicial es schwa, casi no se oye)
computer → kəm-PIÚ-tər (primera y última vocal son schwa)
develop  → dɪ-VÉ-ləp (la "o" final es schwa)
```

## 2. Consonantes Problemáticas para Hispanohablantes

| Sonido | Problema | Cómo hacerlo | Ejemplo |
|--------|----------|-------------|---------|
| /θ/ (th suave) | No existe en español mexicano | Lengua ENTRE los dientes + soplar | **think** = "zink" (con lengua entre dientes) |
| /ð/ (th sonora) | Tampoco existe | Igual que /θ/ pero vibrando la garganta | **this** = "dis" (con lengua entre dientes + vibración) |
| /v/ | Españoles dicen "b" | Dientes superiores tocan labio inferior | **very** ≠ "bery". Muerde tu labio inferior |
| /z/ | No existe en español latam | Como la "s" pero vibrando la garganta | **zero** = "siiro" con vibración |
| /ʃ/ (sh) | "sh" como cuando mandas callar | Labios redondos, aire sale suave | **she** = "shi" |
| /ʒ/ | Como sh pero con vibración | | **measure** = "méʒer" |
| /dʒ/ (j) | Similar a "y" argentina fuerte | | **job** = "yob" (fuerte) |
| /r/ | MUY diferente a la "r" española | Lengua NO toca nada (se curva hacia atrás) | **red** (no rrred, no rr) |
| /h/ | En español la "h" es muda | En inglés SÍ se pronuncia (como aspirar) | **house** = "jaus" (aspira aire) |
| /w/ | Labios redondos como "u" + abrir | | **water** = "uóter" |
| /ŋ/ (ng) | Como la "n" en "tengo" | | **king** = "kiŋ" (no "king-gue") |

## 3. Reglas de Pronunciación (las más útiles)

### Vocales largas vs cortas (cambian el significado)
```
ship /ʃɪp/ (barco)     vs    sheep /ʃiːp/ (oveja)
bit /bɪt/ (poco)       vs    beat /biːt/ (golpear)
full /fʊl/ (lleno)     vs    fool /fuːl/ (tonto)
```

### La "e" muda al final
Cuando una palabra termina en "e", esa "e" NO se pronuncia pero cambia la vocal anterior:
```
hat  (jat)   →  hate  (jéit)     ← la "e" final hace la "a" larga
bit  (bit)   →  bite  (báit)     ← la "e" final hace la "i" larga
not  (not)   →  note  (nóut)     ← la "e" final hace la "o" larga
cut  (cat)   →  cute  (kiút)     ← la "e" final hace la "u" larga
```

### Letras que NO se pronuncian (silent letters)
```
know   → "nou" (la k es muda)
write  → "rait" (la w es muda)
doubt  → "daut" (la b es muda)
island → "áiland" (la s es muda)
listen → "lísen" (la t es muda)
```

### "-tion" y "-sion" = "shon" y "zhon"
```
nation     → "néishon"
information → "informéishon"
decision   → "disízhon"
```

### "-ight" = "ait"
```
night → "nait"
right → "rait"
light → "lait"
fight → "fait"
```

## 5. Ejercicios Diarios (10 minutos)

### Ejercicio 1: Pares mínimos (repetir 5 veces cada uno)
```
ship / sheep       (barco / oveja)
bit / beat         (poco / golpear)
cat / cut          (gato / cortar)
full / fool        (lleno / tonto)
bed / bad          (cama / malo)
```

### Ejercicio 2: Trabalenguas
```
"She sells seashells by the seashore"
(shi sels síshels bai da síshore)

"The thirty-three thieves thought that they thrilled the throne"
(da zérti-zrii zíivs zot dat dei zrild da zróun)

"Red lorry, yellow lorry" (x5 rápido)
(red lóri, yelou lóri)
```

### Ejercicio 3: Leer código en voz alta
```java
public static void main(String[] args)
→ "páblik státik void méin string args"

System.out.println("Hello World")
→ "sístem aut print-láin jélo uorld"

if (user != null && user.isActive())
→ "if iúser not íkuals nol and iúser is áctiv"
```

## 6. Recursos para Practicar Pronunciación

### Apps gratuitas:
- **ELSA Speak** — Detecta errores de pronunciación con IA
- **Forvo.com** — Escucha cómo nativos pronuncian cualquier palabra
- **YouGlish.com** — Busca una palabra y te muestra videos de nativos usándola

### Técnica del "Shadowing":
1. Pon un video/podcast en inglés
2. Pausa después de cada oración
3. REPITE imitando la entonación EXACTA
4. No te preocupes por entender todo, enfócate en el SONIDO

### Canales de YouTube:
- **Rachel's English** — Pronunciación americana detallada
- **English with Lucy** — Pronunciación británica
- **Pronunciation with Emma** — Sonidos difíciles explicados
