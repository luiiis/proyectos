# Módulo 06: Gramática Media — Tiempos Compuestos y Condicionales

## 1. Presente Perfecto (have/has + participio)
"Algo que pasó en el pasado pero tiene efecto AHORA"

| Español | Inglés | Pronunciación |
|---------|--------|---------------|
| He desplegado 3 veces hoy | I have deployed 3 times today | "ái jav diplóid zrí táims tudéi" |
| Ella nunca ha usado Docker | She has never used Docker | "shí jas néver iúsd Dóker" |
| ¿Has terminado el PR? | Have you finished the PR? | "jav iú fínisht da pí-ár?" |
| No he encontrado el bug | I haven't found the bug yet | "ái jávnt fáund da bag iet" |

### Palabras clave del presente perfecto:
- **already** (ya): "I've already fixed it"
- **yet** (aún/todavía): "I haven't tested it yet"
- **just** (recién): "I've just deployed"
- **never** (nunca): "I've never used MongoDB"
- **ever** (alguna vez): "Have you ever used Kafka?"
- **since** (desde): "I've been a developer since 2020"
- **for** (durante): "I've worked here for 3 years"

## 2. Pasado Continuo (was/were + verbo-ing)
"Algo que estaba pasando cuando otra cosa ocurrió"

```
I was coding when the server crashed
(Estaba programando cuando se cayó el servidor)

We were testing when the client called
(Estábamos probando cuando llamó el cliente)
```

## 3. Condicionales

### Zero conditional (hechos, siempre verdad):
```
If you delete the database, you lose all data.
(Si borras la BD, pierdes todos los datos)
→ Estructura: If + presente, presente
```

### First conditional (posibilidad real futura):
```
If we finish today, we will deploy tomorrow.
(Si terminamos hoy, desplegamos mañana)
→ Estructura: If + presente, will + verbo
```

### Second conditional (hipotético/improbable):
```
If I had more time, I would refactor the entire module.
(Si tuviera más tiempo, refactorizaría todo el módulo)
→ Estructura: If + pasado, would + verbo
```

### Third conditional (pasado irreal, ya no se puede cambiar):
```
If we had added tests, we would have caught the bug earlier.
(Si hubiéramos agregado tests, habríamos encontrado el bug antes)
→ Estructura: If + had + participio, would have + participio
```

## 4. Voz Pasiva (cuando importa QUÉ pasó, no QUIÉN lo hizo)

```
Activa: "The team deployed the update" (El equipo desplegó)
Pasiva: "The update was deployed" (La actualización fue desplegada)

Activa: "Someone broke the build"
Pasiva: "The build was broken" (El build se rompió)

Activa: "We will release the feature next week"
Pasiva: "The feature will be released next week"
```

En tech se usa MUCHO la pasiva:
- "The issue has been resolved" (El issue fue resuelto)
- "Access was denied" (Acceso denegado)
- "The request was rejected" (La petición fue rechazada)
- "The migration will be run tonight" (La migración se ejecutará esta noche)

## 5. Reported Speech (reportar lo que alguien dijo)

```
Directo: Carlos said "The API is ready"
Indirecto: Carlos said (that) the API was ready

Directo: She said "I will fix it tomorrow"
Indirecto: She said she would fix it the next day

Directo: They asked "When is the deadline?"
Indirecto: They asked when the deadline was
```

Útil en emails: "As mentioned in the meeting, the deadline is Friday"
