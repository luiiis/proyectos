### En Code Review
| Español | Inglés |
|---------|--------|
| ¿Puedes agregar un comentario aquí? | Can you add a comment here? |
| Creo que esto debería ser una función separada | I think this should be a separate function |
| ¿Por qué no usas un Map en vez de un array? | Why not use a Map instead of an array? |
| Falta validación en este input | Input validation is missing here |
| LGTM (Looks Good To Me) | Se ve bien, aprobado |
| Nit: (nitpick, detalle menor) | Small suggestion, not blocking |

### Reportar un Bug
```
"I found a bug in the login page.

Steps to reproduce:
1. Go to /login
2. Enter a valid username but wrong password
3. Click 'Submit'

Expected: Show error message 'Invalid credentials'
Actual: The page crashes with a 500 error

Environment: Chrome 120, Windows 11
```

## 3. Leer Documentación en Inglés

### Palabras clave en docs:
| Inglés | Español | Dónde la ves |
|--------|---------|--------------|
| Getting Started | Primeros pasos | Inicio de cualquier doc |

| Usage | Uso | Cómo usar |
| API Reference | Referencia de API | Lista de métodos |
| Parameters | Parámetros | Qué recibe una función |
| Returns | Retorna | Qué devuelve |
| Throws | Lanza (excepción) | Qué errores puede dar |
| Deprecated | Obsoleto | No usar, hay alternativa |
| Note/Warning | Nota/Advertencia | Información importante |
| Example | Ejemplo | Código de muestra |
| See also | Ver también | Referencias relacionadas |
| Required | Requerido | Obligatorio |
| Optional | Opcional | No obligatorio |
| Default | Valor por defecto | Si no especificas nada |

### Errores comunes en logs (traducidos):
```
"NullPointerException"       → Intentaste usar algo que es null
"Connection refused"         → El servidor rechazó la conexión (no está corriendo)
"Permission denied"          → No tienes permisos
"File not found"             → El archivo no existe
"Out of memory"              → Se acabó la memoria RAM
"Timeout exceeded"           → Tardó demasiado y se canceló
"Invalid argument"           → Le pasaste un dato incorrecto
"Already exists"             → Ya existe (duplicado)
"Not found"                  → No se encontró
"Unauthorized"               → No estás autenticado
"Forbidden"                  → Estás autenticado pero sin permisos
"Internal Server Error"      → Algo falló en el servidor (bug)
"Bad Request"                → Tu petición tiene errores
"Conflict"                   → Conflicto (ej: email duplicado)
```

## 5. Ejercicio: Escribe un Commit Message en Inglés

### Formato estándar:
```
tipo: descripción corta (imperativo, <50 chars)

Cuerpo explicativo opcional (qué y por qué, no cómo)

Closes #123
```

### Ejemplos buenos:
```
feat: add user registration endpoint
fix: resolve null pointer in product search
refactor: extract validation logic to service layer
docs: update API documentation for auth endpoints
test: add unit tests for order service
chore: upgrade Spring Boot to 3.3.5
```

### Practica: traduce estos commits:
```
Español: "arreglé el error del login"
Inglés:  "fix: resolve login authentication error"

Español: "agregué validación al formulario de productos"
Inglés:  "feat: add validation to product form"

Español: "actualicé las dependencias de Maven"
Inglés:  "chore: update Maven dependencies"
```
