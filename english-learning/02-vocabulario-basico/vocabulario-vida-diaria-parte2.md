## 😊 EMOCIONES Y SENTIMIENTOS (Emotions & Feelings)

### Emociones básicas
| Español | Inglés | Pronunciación | Ejemplo |
|---------|--------|---------------|---------|
| Feliz/Contento | Happy | "jápi" | I'm happy with the results |
| Triste | Sad | "sad" | I'm sad about the layoffs |
| Enojado | Angry / Mad | "ángri" / "mad" | I'm angry about the bug |
| Cansado | Tired | "táierd" | I'm tired, long day |
| Emocionado | Excited | "eksáited" | I'm excited about the new project |
| Nervioso | Nervous | "nérvos" | I'm nervous about the interview |
| Preocupado | Worried | "uórid" | I'm worried about the deadline |
| Aburrido | Bored | "bord" | This meeting is boring |
| Sorprendido | Surprised | "serpráizd" | I'm surprised it works! |
| Confundido | Confused | "konfiúzd" | I'm confused by this code |
| Frustrado | Frustrated | "frastréited" | I'm frustrated with this bug |
| Orgulloso | Proud | "práud" | I'm proud of our team |
| Estresado | Stressed | "strest" | I'm stressed about the release |
| Tranquilo | Calm / Relaxed | "kam" / "riláxd" | Stay calm, we'll fix it |
| Seguro | Confident | "kónfident" | I'm confident it'll work |
| Asustado | Scared / Afraid | "skérd" / "afréid" | I'm afraid of breaking production |

### Cómo expresar emociones:
```
"I feel..." (me siento...)
  I feel tired → Me siento cansado
  I feel great → Me siento genial
  I feel overwhelmed → Me siento abrumado

"I'm..." (estoy...)
  I'm happy → Estoy feliz
  I'm stressed → Estoy estresado

"It makes me..." (me hace sentir...)
  It makes me angry → Me hace enojar
  It makes me proud → Me hace sentir orgulloso
```

### Emociones en el trabajo:
| Situación | Cómo expresarlo |
|-----------|----------------|
| Conseguiste algo difícil | "I'm proud of what we accomplished" |
| Mucho trabajo | "I'm feeling overwhelmed right now" |
| Buenas noticias | "That's great news! I'm excited" |
| Problema sin solución | "I'm frustrated, nothing seems to work" |
| Antes de una demo | "I'm a bit nervous but prepared" |
| Después de un logro | "I feel satisfied with the result" |
| Fin de semana | "I'm looking forward to the weekend" |

## 🗓️ EJERCICIO SEMANAL COMPLETO

### Lunes: Frutas + Verduras
```
Voy al super. Digo en inglés todo lo que veo:
"Apples, bananas, oranges... tomatoes, onions, potatoes..."
```

### Martes: Acciones de la mañana
```
Narro mi rutina mientras la hago:
"I'm waking up... I'm taking a shower... I'm brushing my teeth..."
```

### Miércoles: La casa
```
Camino por mi casa señalando:
"This is the kitchen... that's the fridge... here's the couch..."
```

### Jueves: Emociones
```
Cada vez que sienta algo, lo digo:
"I'm tired... I'm frustrated with this bug... I'm happy it works!"
```

### Viernes: Ropa + Colores
```
Describo lo que traigo puesto:
"I'm wearing a blue t-shirt, black jeans, and white sneakers"
```

### Sábado: Lugares + Direcciones
```
Describo a dónde voy:
"I'm going to the supermarket. It's near my house, on the left."
```

### Domingo: Repaso general
```
Escribo un párrafo describiendo mi semana usando todas las categorías.
```
