# Módulo 11: Presentaciones — Demos Técnicas y Hablar en Público

## 1. Estructura de una Demo Técnica (5-10 min)

```
1. CONTEXTO (30 seg): "Today I'll show you how [feature] works"
2. PROBLEMA (1 min): "The problem we were solving is..."
3. SOLUCIÓN (3-5 min): Demo en vivo con explicación
4. RESULTADO (1 min): "As you can see, now we can..."
5. PREGUNTAS (2 min): "Any questions?"
```

### Frases para cada parte:

**Inicio:**
```
"Hi everyone, today I want to show you..."
"Let me quickly demo the new product search feature"
"I'll walk you through how the authentication flow works"
```

**Transiciones:**
```
"So first, let me start the application..."
"Now, if I click here..."
"As you can see on the screen..."
"Next, let me show you what happens when..."
"Moving on to the error handling..."
```

**Cuando algo sale mal (siempre pasa):**
```
"Give me a second, let me restart the service"
"That's not supposed to happen — let me check the logs"
"Interesting bug! I'll fix that after the demo"
"The WiFi seems slow, but you get the idea"
```

**Cierre:**
```
"So that's the feature. Any questions?"
"To summarize: we now have search, filtering, and pagination"
"I'll share the PR link in Slack if you want to review the code"
```

## 2. Sprint Review / Demo al Cliente

```
"In this sprint, we completed 3 stories:

First, we implemented the product search with full-text support.
Users can now find products by name, category, or description.

Second, we added stock alerts. When inventory drops below the
minimum, the system automatically notifies the warehouse team.

Third, we fixed the performance issue in the reports page.
Loading time went from 8 seconds down to 200 milliseconds.

For next sprint, we're planning to work on the checkout flow
and payment integration. Any questions?"
```
