# Módulo 04: Conversación — Frases del Día a Día

## 1. Saludos y Despedidas

| Español | Inglés | Pronunciación | Cuándo usarlo |
|---------|--------|---------------|---------------|
| Hola | Hi / Hey | "jái" / "jéi" | Informal, amigos, equipo |
| Buenos días | Good morning | "gud mórning" | Antes de mediodía |
| Buenas tardes | Good afternoon | "gud afternún" | 12pm - 6pm |
| Buenas noches | Good evening | "gud ívning" | Después de 6pm |
| ¿Cómo estás? | How are you? | "jáu ar iú?" | Saludo estándar |
| Bien, ¿y tú? | Good, and you? | "gud, and iú?" | Respuesta estándar |
| Nos vemos | See you / See ya | "si iú" / "si ya" | Despedida casual |
| Hasta mañana | See you tomorrow | "si iú tumórou" | Al terminar el día |
| Que te vaya bien | Take care | "téik kér" | Despedida amable |
| Buen fin de semana | Have a good weekend | "jav a gud uíkend" | Viernes |

## 3. En una Meeting/Call

### Inicio:
```
"Can everyone hear me?" → ¿Me escuchan todos?
"Let me share my screen" → Déjame compartir pantalla
"Let's get started" → Empecemos
"Is everyone here?" → ¿Estamos todos?
```

### Durante:
```
"Sorry, you're breaking up" → Perdón, se corta el audio
"Can you repeat that?" → ¿Puedes repetir?
"I have a question" → Tengo una pregunta
"Going back to what you said..." → Volviendo a lo que dijiste...
"To summarize..." → Para resumir...
"Any concerns?" → ¿Alguna preocupación?
```

### Fin:
```
"Any questions before we wrap up?" → ¿Preguntas antes de terminar?
"I'll send a summary by email" → Envío un resumen por email
"Thanks everyone, have a good day" → Gracias a todos, buen día
"Let's follow up on Slack" → Seguimos por Slack
```

## 4. Expresiones Comunes en Tech

| Expresión | Significado | Ejemplo |
|-----------|------------|---------|
| "heads up" | aviso/advertencia | Heads up: I'm deploying in 10 min |
| "FYI" (for your information) | para tu información | FYI, the meeting moved to 3 PM |
| "ASAP" (as soon as possible) | lo antes posible | Fix this ASAP |
| "ETA" (estimated time of arrival) | ¿cuándo estará listo? | What's the ETA on the fix? |
| "LGTM" (looks good to me) | se ve bien, aprobado | LGTM, merging now |
| "WIP" (work in progress) | en progreso | WIP: don't merge yet |
| "TL;DR" (too long; didn't read) | resumen | TL;DR: use PostgreSQL |
| "EOD" (end of day) | antes de que termine el día | I'll finish by EOD |
| "OOO" (out of office) | fuera de oficina | I'm OOO tomorrow |
| "IMO" (in my opinion) | en mi opinión | IMO we should refactor first |
