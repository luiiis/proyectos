# Módulo 03: Gramática Básica — Estructura de Oraciones

## La Regla #1 del Inglés
**El orden SIEMPRE es: Sujeto + Verbo + Complemento**

```
Español: "Ayer comí pizza" (Tiempo + Verbo + Objeto) ← flexible
Inglés:  "I ate pizza yesterday" (S + V + O + Tiempo) ← FIJO
```

---

## 1. Presente Simple (cosas que haces regularmente)

### Estructura:
```
(+) Sujeto + verbo (+ s/es si es he/she/it)
(-) Sujeto + don't/doesn't + verbo
(?) Do/Does + sujeto + verbo?
```

### Ejemplos:
| Español | Inglés | Pronunciación |
|---------|--------|---------------|
| Yo trabajo aquí | I work here | "ái uork jír" |
| Ella escribe código | She writes code | "shí ráits kóud" |
| Nosotros usamos Java | We use Java | "uí iúz yáva" |
| Yo no entiendo | I don't understand | "ái dóunt anderstánd" |
| Él no habla español | He doesn't speak Spanish | "jí dásnt spík spánish" |
| ¿Tú sabes Python? | Do you know Python? | "du iú nóu páizon?" |
| ¿Ella trabaja remoto? | Does she work remotely? | "das shí uork rimóutli?" |

### Regla de la "s" en tercera persona (he/she/it):
```
I work     → He works
I go       → She goes (termina en o → "es")
I study    → He studies (termina en y → "ies")
I watch    → She watches (termina en ch/sh/x → "es")
I have     → He has (irregular)
I do       → She does (irregular)
```

## 2. Presente Continuo (lo que estás haciendo AHORA)

### Estructura:
```
(+) Sujeto + am/is/are + verbo-ing
(-) Sujeto + am/is/are + not + verbo-ing
(?) Am/Is/Are + sujeto + verbo-ing?
```

### Ejemplos:
| Español | Inglés | Pronunciación |
|---------|--------|---------------|
| Estoy programando | I am coding | "áim kóuding" |
| Está cargando | It is loading | "it is lóuding" |
| Estamos desplegando | We are deploying | "uír diplóiing" |
| No estoy trabajando | I'm not working | "áim not uórking" |
| ¿Estás escuchando? | Are you listening? | "ar iú lísening?" |

### Presente Simple vs Continuo:
```
I write code (every day)        → Presente Simple (hábito/rutina)
I am writing code (right now)   → Presente Continuo (ahora mismo)

The server runs on port 8080    → Simple (estado permanente)
The server is running slowly    → Continuo (temporalmente ahora)
```

## 3. Pasado Simple (algo que ya pasó)

### Estructura:
```
(+) Sujeto + verbo en pasado (-ed / irregular)
(-) Sujeto + didn't + verbo base
(?) Did + sujeto + verbo base?
```

### Verbos regulares: agregar -ed
```
work → worked (uorkt)
fix → fixed (fikst)
deploy → deployed (diplóid)
create → created (kriéited)
```

## 4. Futuro (planes y predicciones)

### Con "will" (decisiones espontáneas, predicciones):
```
I will fix it tomorrow        → "áil fíks it tumórou"
It will take 2 hours          → "it uíl téik tu áuers"
We will deploy on Friday      → "uíl diplói on fráidei"
```

### Con "going to" (planes ya decididos):
```
I'm going to refactor this    → "áim góuing tu rifáctor dis"
We're going to migrate to AWS → "uír góuing tu maigréit tu éi-dábel-iu-es"
```

## 5. Verbos Modales (los más útiles)

| Modal | Significado | Ejemplo | Pronunciación |
|-------|------------|---------|---------------|
| can | poder/saber | I can help you | "ái kan jelp iú" |
| can't | no poder | I can't reproduce the bug | "ái kant riprodúis da bag" |
| should | debería | You should add tests | "iú shud ad tests" |
| shouldn't | no debería | We shouldn't deploy on Friday | "uí shúdnt diplói on fráidei" |
| must | deber (obligación) | You must use HTTPS | "iú mast iús éich-ti-ti-pí-és" |
| could | podría | Could you review my PR? | "kud iú rivíu mái pí-ár?" |
| would | (condicional) | I would use PostgreSQL | "ái uud iús post-gres" |
| might | podría (posibilidad) | It might be a race condition | "it máit bi a réis condíshon" |

## 6. Preguntas — Cómo Formarlas

### Patrón universal:
```
Palabra interrogativa + auxiliar + sujeto + verbo + complemento?
```

### Ejemplos prácticos:
| Español | Inglés | Patrón |
|---------|--------|--------|
| ¿Qué hace este código? | What does this code do? | What + does + this code + do? |
| ¿Dónde está el error? | Where is the error? | Where + is + the error? |
| ¿Cuándo desplegamos? | When are we deploying? | When + are + we + deploying? |
| ¿Por qué falló? | Why did it fail? | Why + did + it + fail? |
| ¿Cómo lo arreglo? | How do I fix it? | How + do + I + fix it? |
| ¿Cuánto tarda? | How long does it take? | How long + does + it + take? |
| ¿Quién escribió esto? | Who wrote this? | Who + wrote + this? (sin auxiliar) |

## 7. Conectores para Sonar Fluido

| Español | Inglés | Ejemplo |
|---------|--------|---------|
| Primero | First | First, I'll check the logs |
| Luego/Después | Then / After that | Then I'll fix the query |
| Además | Also / Additionally | Also, we need to add tests |
| Sin embargo | However / But | However, it might break other things |
| Por lo tanto | So / Therefore | So we should create a new branch |
| Por ejemplo | For example | For example, we could use Redis |
| En otras palabras | In other words | In other words, it's a memory leak |
| Finalmente | Finally | Finally, we'll deploy to production |
| En resumen | In summary | In summary, we need 3 days |
