## 1. Phrasal Verbs en Tech (los más usados)

| Phrasal Verb | Significado | Ejemplo |
|-------------|------------|---------|
| set up | configurar | Set up the environment |
| look into | investigar | I'll look into the issue |
| figure out | descubrir/resolver | I figured out the bug |
| come up with | idear/proponer | We came up with a solution |
| run into | encontrarse con (problema) | I ran into an error |
| break down | dividir en partes | Let's break down the task |
| roll back | revertir | Roll back the deployment |
| spin up | levantar/iniciar | Spin up a new container |
| scale up | escalar (más grande) | We need to scale up |
| shut down | apagar | Shut down the server |
| log in / log out | iniciar/cerrar sesión | Log in to the dashboard |
| sign up | registrarse | Sign up for an account |
| opt in / opt out | aceptar/rechazar | Users can opt out of notifications |
| follow up | dar seguimiento | I'll follow up tomorrow |
| wrap up | terminar/concluir | Let's wrap up the meeting |
| bring up | mencionar | I want to bring up a concern |
| point out | señalar | She pointed out a typo |
| work around | encontrar alternativa | We can work around it |
| end up | terminar siendo | We ended up using Redis |
| turn out | resultar ser | It turned out to be a race condition |

## 2. Expresiones Idiomáticas Comunes en el Trabajo

| Expresión | Significado | Contexto |
|-----------|------------|----------|
| "On the same page" | Estar de acuerdo/alineados | "Let's make sure we're on the same page" |
| "Low-hanging fruit" | Tarea fácil con mucho impacto | "Let's start with the low-hanging fruit" |
| "Move the needle" | Hacer una diferencia significativa | "Will this move the needle?" |
| "Deep dive" | Investigar a fondo | "Let's do a deep dive into the logs" |
| "Touch base" | Hacer check-in/contacto breve | "Let's touch base tomorrow" |
| "Circle back" | Volver a un tema después | "Let me circle back on that" |
| "Hit the ground running" | Empezar productivo desde el día 1 | "I want to hit the ground running" |
| "At the end of the day" | En resumen/lo que importa | "At the end of the day, it needs to work" |
| "Take it offline" | Discutir fuera de la reunión | "Let's take this offline" |
| "Ballpark" | Estimación aproximada | "Give me a ballpark estimate" |
| "Heads up" | Aviso/alerta | "Heads up: deploying in 10 min" |
| "No-brainer" | Decisión obvia | "Using Docker is a no-brainer" |

## 3. Cultura Laboral Anglosajona (lo que nadie te dice)

### Comunicación indirecta:
```
Español: "Está mal, cámbialo" (directo)
Inglés: "I was wondering if we could maybe look at another approach" 
(indirecto — pero SIGNIFICA lo mismo)

"Interesting approach" = No me convence
"I have a few thoughts" = Tengo objeciones
"Let's revisit this" = No estoy de acuerdo pero no quiero pelear
"Going forward" = Olvidemos lo que pasó
```

### Small talk (charla informal):
```
ANTES de la meeting (1-2 min):
"How was your weekend?"
"Did you watch the game?"
"Nice weather today"
"How's the new apartment?"

NO hablar de: salario, edad, religión, política, peso
SÍ hablar de: clima, deportes, series/películas, comida, viajes, mascotas
```
