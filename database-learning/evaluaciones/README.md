| [Examen 06-12](examen-modulo-06-12.md) | Funciones → Transacciones | Mid | 90 min |

## Cómo tomar un examen

1. Abre el archivo del examen
2. Lee las instrucciones (tiempo, reglas)
3. Usa la BD `empresa_db` (levanta Docker)
4. NO consultes documentación ni soluciones
5. Escribe tus queries en un archivo `.sql`
6. Al terminar, compara con los criterios de evaluación

## Criterios de aprobación

```
60-69 pts: Aprobado (necesitas repasar)
70-79 pts: Bien (conocimiento sólido)
80-89 pts: Muy bien (listo para entrevista junior)
90-100 pts: Excelente (nivel mid para SQL)
```

## Tip: Simula una entrevista técnica

Pon un timer de 45 minutos y resuelve la Sección B sin ayuda. Esto simula la presión de una entrevista técnica real donde te piden resolver queries en vivo.
