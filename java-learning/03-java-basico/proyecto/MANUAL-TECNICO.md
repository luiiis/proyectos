# Módulo 03: Java Básico - Manual Técnico

## ¿Qué construimos?
Programas Java ejecutables que cubren: variables, operadores, control de flujo, Scanner, Strings y Arrays.

## Cómo ejecutar
```bash
cd java-learning/03-java-basico/proyecto

# Compilar todos los archivos
javac *.java

# Ejecutar cada programa
java Ejercicio01_Variables
java Ejercicio02_Calculadora
java Ejercicio03_FizzBuzz
```

## O con JShell (interactivo)
```bash
jshell
jshell> /open Ejercicio01_Variables.java
```
