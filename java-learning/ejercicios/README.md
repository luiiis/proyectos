# Sistema de Ejercicios - 900 Ejercicios Clasificados

## Estructura
- Básicos (B001-B300): Módulos 1-8
- Intermedios (I001-I300): Módulos 9-17
- Avanzados (A001-A300): Módulos 18-30

## Reglas
1. Intenta resolver SIN ver la solución
2. Soluciones en `/soluciones/`
3. Si te atoras más de 30 min, ve una PISTA (no la solución completa)
4. Después de resolver, compara con la solución óptima

## Ejercicios Básicos (Muestra)

### B001 - Suma de dígitos
Escribe un método que reciba un entero y devuelva la suma de sus dígitos.
`sumaDigitos(1234)` → `10`

### B002 - Palíndromo
Determina si un string es palíndromo (se lee igual al derecho y al revés).
`esPalindromo("anilina")` → `true`

### B003 - Fibonacci
Genera los primeros N números de Fibonacci.
`fibonacci(7)` → `[0, 1, 1, 2, 3, 5, 8]`

### B004 - Máximo en array
Encuentra el valor máximo en un array sin usar Arrays.sort().

### B005 - Contar vocales
Cuenta las vocales en un string (incluyendo acentuadas).
