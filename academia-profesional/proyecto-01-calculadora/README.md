# Proyecto 01: Calculadora Java

## ¿Qué problema resuelve?
Aprender los fundamentos de Java construyendo algo funcional: una calculadora de consola con operaciones básicas, historial y validaciones.

## Tecnologías
- Java 21
- Scanner (entrada de datos)
- Switch expressions (Java 14+)
- Records (Java 16+)
- ArrayList (historial)

## Funcionalidades
- Operaciones: +, -, *, /, %, potencia
- Historial de operaciones
- Validación de entrada
- Manejo de errores (división por cero)
- Menú interactivo
