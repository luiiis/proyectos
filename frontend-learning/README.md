# 🎓 Academia Completa: Frontend + Angular + TypeScript + Arquitectura

## De Principiante Absoluto a Senior Frontend Engineer / Arquitecto Angular

Academia estructurada en 30 módulos: desde "¿cómo funciona Internet?" hasta construir sistemas enterprise con Angular, micro-frontends y arquitectura limpia.

---

## Roadmap

```
FASE 1: Web Fundamentals (Módulos 1-9) ─── 8-10 semanas
  │  HTML, CSS, JavaScript, TypeScript, DOM, Async
  │
FASE 2: Angular Core (Módulos 10-18) ─── 8-10 semanas
  │  Componentes, servicios, RxJS, routing, forms
  │
FASE 3: UI Libraries + State (Módulos 19-21) ─── 4 semanas
  │  Angular Material, PrimeNG, Signals/NgRx
  │
FASE 4: Quality + DevOps (Módulos 22-27) ─── 6 semanas
  │  Testing, performance, accesibilidad, Docker, CI/CD
  │
FASE 5: Architecture + Final (Módulos 28-30) ─── 6 semanas
     Clean Architecture, micro-frontends, proyecto enterprise
```

## Requisitos
- Computadora con navegador moderno (Chrome/Firefox)
- VS Code con extensiones: Angular Language Service, Prettier, ESLint
- Node.js 20+ y npm
- Angular CLI: `npm install -g @angular/cli`
