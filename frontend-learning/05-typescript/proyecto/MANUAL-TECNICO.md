# Módulo 05: TypeScript - Manual Técnico

## ¿Qué construimos?
Ejercicios TypeScript que demuestran el sistema de tipos, interfaces, generics y patrones usados en Angular.

## Cómo ejecutar
```bash
# Instalar TypeScript globalmente
npm install -g typescript ts-node

# Ejecutar directamente
ts-node ejercicios.ts

# O compilar y ejecutar
tsc ejercicios.ts && node ejercicios.js
```

## ¿Por qué TypeScript?
JavaScript no tiene tipos → errores en runtime que podrían detectarse antes.
TypeScript agrega tipos → errores en COMPILACIÓN (antes de ejecutar).
Angular está escrito EN TypeScript → es obligatorio aprenderlo.
