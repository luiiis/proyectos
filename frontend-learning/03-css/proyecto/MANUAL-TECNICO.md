# Módulo 03: CSS3 - Manual Técnico

## ¿Qué construimos?
Un dashboard responsive usando Flexbox y Grid que se adapta a móvil, tablet y desktop.

## Cómo ejecutar
```bash
# Abrir en navegador
open index.html
# O con Live Server en VS Code
```

## Conceptos demostrados
- Flexbox (navegación, cards)
- CSS Grid (layout del dashboard)
- Media Queries (responsive)
- Variables CSS (custom properties)
- Transiciones y hover effects
