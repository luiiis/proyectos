Ejercicios progresivos de JavaScript puro (sin frameworks) que cubren los fundamentos necesarios antes de aprender Angular.

```bash
node ejercicios.js

# Opción 2: En el navegador (abrir index.html y ver consola F12)

# Opción 3: En VS Code con Code Runner (extensión)
```
