# Nivel 11: Proyecto Full Stack Intermedio — Sistema de Inventario

## Objetivo
Construir una aplicación REAL con múltiples módulos, como se haría en una empresa.

## Módulos
- Usuarios + Roles + Permisos
- Categorías
- Productos
- Proveedores
- Compras (entrada de mercancía)
- Salidas de inventario
- Ajustes de inventario
- Existencias actuales
- Historial de movimientos
- Reportes

## Funcionalidades técnicas
- Transacciones (compra = cabecera + detalles + actualizar stock)
- Auditoría (quién hizo qué y cuándo)
- Paginación server-side
- Filtros combinados
- Exportación a Excel/PDF
- Carga de imágenes de productos
- Validación de archivos
- Logs de errores
- Correos (alerta de stock bajo)
