# Nivel 12: Proyecto Full Stack Profesional — Depósitos ERP

## Objetivo
Construir un ERP completo que puede convertirse en un PRODUCTO REAL.

## Módulos
- Autenticación + Usuarios + Roles + Permisos
- Sucursales
- Cajas
- Clientes + Proveedores
- Categorías + Productos
- Inventario (existencias por sucursal)
- Compras
- Ventas + Tickets
- Cortes de caja
- Gastos
- Entradas y salidas de efectivo
- Reportes
- Auditoría
- Configuración del sistema
- Notificaciones

## 10 Versiones Profesionales

| V | Qué agrega |
|---|------------|
| 1 | Monolito básico (backend + frontend + BD) |
| 2 | Monolito modular (separar módulos internamente) |
| 3 | Arquitectura hexagonal |
| 4 | Multiusuario (roles y permisos completos) |
| 5 | Multisucursal (stock por sucursal) |
| 6 | Multiempresa (tenant isolation) |
| 7 | Docker (contenedores para todo) |
| 8 | CI/CD (compilar + test + deploy automático) |
| 9 | Monitoreo (Actuator + métricas + logs + alertas) |
| 10 | Producción (HTTPS, dominio, backups, auditoría) |
