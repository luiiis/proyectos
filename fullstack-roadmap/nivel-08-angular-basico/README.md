# Nivel 8: Angular desde Cero — Proyecto 8: Aprender Angular

## Objetivo
Aprender Angular SIN backend. Construir mini-aplicaciones para dominar componentes, servicios, rutas y formularios.

## Temas
- Instalar Angular CLI
- Crear proyecto (standalone)
- Estructura de carpetas
- Componentes
- Templates y estilos
- Variables y eventos
- @if, @for, @switch
- Formularios (reactivos)
- Rutas y navegación
- Servicios e inyección
- Interfaces TypeScript
- Pipes y directivas
- Comunicación entre componentes (Input/Output)
- Signals

## Mini-aplicaciones que construiremos
1. **Contador** — Signals básicos
2. **Calculadora** — Eventos y lógica
3. **Lista de Tareas** — CRUD local con Signals
4. **Formulario de Productos** — Reactive Forms + validaciones
5. **Catálogo visual** — Routing + componentes reutilizables
