# Nivel 9: Angular + Backend — Proyecto 9: Frontend de Productos

## Objetivo
Conectar Angular con la API de Spring Boot. CRUD completo con interfaz gráfica.

## Funcionalidades
- Listar productos (tabla)
- Crear productos (formulario)
- Modificar productos
- Eliminar productos (con confirmación)
- Buscar por nombre
- Filtrar por categoría
- Paginación
- Mensajes de éxito y error

## 8 Versiones
| V | Qué agrega |
|---|------------|
| 1 | Todo en un solo componente |
| 2 | Separar componentes (lista, form, detalle) |
| 3 | Crear servicios HTTP |
| 4 | Formularios reactivos con validaciones |
| 5 | Componentes reutilizables (tabla genérica, modal) |
| 6 | Tabla con paginación server-side |
| 7 | Mensajes toast y modales de confirmación |
| 8 | Manejo global de errores (interceptor) |

## Conceptos
- HttpClient
- Servicios Angular
- Observables y RxJS
- Interfaces TypeScript
- Variables de entorno
- CORS (comunicación frontend↔backend)
- Formularios reactivos + validaciones
