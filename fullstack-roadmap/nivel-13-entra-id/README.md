# Nivel 13: Identidad Profesional — Microsoft Entra ID

## Objetivo
Integrar un proveedor de identidad corporativo (OAuth2 + OpenID Connect) después de dominar JWT custom.

## Temas
- OAuth 2.0 (protocolo de autorización)
- OpenID Connect (capa de identidad sobre OAuth2)
- Access Token, ID Token, Refresh Token
- Claims, Scopes, Roles
- Registro de aplicaciones en Azure
- Tenant, Client ID, Redirect URI
- Angular con MSAL (Microsoft Authentication Library)
- Spring Boot como Resource Server (valida tokens de Entra ID)

## Versiones
| V | Qué implementa |
|---|-----------------|
| 1 | Login local con JWT (ya lo tienes) |
| 2 | Login con Microsoft (redirect a Entra ID) |
| 3 | Login dual (local O Microsoft) |
| 4 | Roles definidos en Entra ID |
| 5 | Permisos de la aplicación (App Roles) |
| 6 | Protección Angular con MSAL |
| 7 | Protección Spring Boot como Resource Server |
| 8 | Administración corporativa |
