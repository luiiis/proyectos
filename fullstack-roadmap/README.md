# 🚀 Ruta Full Stack — De Cero a Profesional

## Tecnologías principales
- Java 21 + Spring Boot 3.3
- Maven
- MyBatis
- MySQL / PostgreSQL
- Angular 20
- Arquitectura Hexagonal
- Spring Security + JWT + OAuth2 + Microsoft Entra ID
- Docker
- Git + GitHub
- Pruebas automatizadas
- Documentación técnica y de usuario

---

## Estructura del Proyecto

```
fullstack-roadmap/
├── nivel-00-preparacion/          → Instalar herramientas
├── nivel-01-backend-basico/       → API de saludos (Proyecto 1)
├── nivel-02-capas/                → CRUD en memoria (Proyecto 2)
├── nivel-03-base-datos/           → Productos + MyBatis (Proyecto 3)
├── nivel-04-pruebas/              → Testing automatizado (Proyecto 4)
├── nivel-05-seguridad/            → Usuarios + JWT (Proyecto 5)
├── nivel-06-profesional/          → Correo + Recuperación (Proyecto 6)
├── nivel-07-arquitectura/         → Hexagonal (Proyecto 7)
├── nivel-08-angular-basico/       → Frontend desde cero (Proyecto 8)
├── nivel-09-angular-backend/      → Angular + API (Proyecto 9)
├── nivel-10-seguridad-fullstack/  → Login Full Stack (Proyecto 10)
├── nivel-11-inventario/           → Sistema intermedio (Proyecto 11)
├── nivel-12-erp/                  → Depósitos ERP (Proyecto 12)
├── nivel-13-entra-id/             → Microsoft Entra ID (Proyecto 13)
└── nivel-14-devops/               → Docker + CI/CD + Producción (Proyecto 14)
```

## Reglas de esta academia

1. **Cada proyecto se trabaja POR VERSIONES** (no todo de golpe)
2. **No avanzas sin terminar la versión actual**
3. **Cada versión tiene documentación**
4. **Cada versión tiene su commit en Git**
5. **Se trabaja paso a paso, como en una empresa real**
